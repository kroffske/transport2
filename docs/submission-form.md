## 5. Дополнительные возможности

```text
- Официальный эмулятор NDTP без изменений в составе compose; драйвер задаёт ему реальные GPS-точки из validate. Ускорение показа ×1–100 (по умолчанию ×5): часы Backend на живом стеке идут с отношением 4,999 при ×5 и 9,995 при ×10.
- Отдельный ML-сервис с выбранной моделью CatBoost (локальная MAE 44,01 с на validate). Каждый прогноз несёт версию модели и SHA-256 артефакта; в карточке ТС видно, на каком кадре NDTP и каком контексте он посчитан.
- Маршрутный контекст выбранного ТС: путь по GPS прогона с пройденной частью, плановые остановки, цель через 10–15 мин. Для остановок до цели — факт, на цели — прогноз модели, после цели — явно подписанное допущение.
- Признак схода с маршрута (off_route, порог 400 м, снятие ниже 250 м) и направление движения ТС (heading).
- Прогон с идентификатором run_id и явными состояниями (ожидание драйвера, запуск, идёт, завершён, ошибка драйвера, остановился). Повторная команда запуска начинает новый прогон; открытая страница сама очищает события и историю.
- Если прогноза нет, карточка называет причину по-русски; вручную заданных значений на экране нет.
- События диспетчера на живых данных: предупреждение при прогнозе больше 2 мин → «Взять в работу» → заметка → история.
- Идентичность сборки: http://localhost:8002/api/build отдаёт source_commit, хэш бандла интерфейса и хэши файлов consumer/static.
- Ограниченные очереди с явными отказами, устойчивость к отказу и медленному ML, повторное подключение NDTP.
- Воспроизводимость: модель и карта лежат в репозитории с SHA-256; внешние файлы проверяются по SHA-256 из README.
Ограничения: модель обучена на одном дне (2026-01-06); прогноз точечный, без вероятности и причины задержки; время раннего предупреждения (lead time) не измерялось.
```
