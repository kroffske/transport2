# Инструкция для жюри

## Быстрый запуск

Из корня репозитория, после подготовки файлов ниже:

```sh
docker compose --profile demo up -d --build --force-recreate
```

Откройте [дашборд](http://localhost:8002). Поток от официального эмулятора и расчёт прогнозов запускаются автоматически.

## Подготовка при первом запуске

Нужны Git и запущенный Docker с Compose v2. На Windows используйте Docker Desktop в режиме Linux containers. Команды подходят для PowerShell, Linux и macOS; Python и Node.js устанавливать не нужно. Для первой сборки нужен интернет.

```sh
git clone https://github.com/kroffske/transport2.git
cd transport2
```

Если репозиторий уже скачан, выполните `git pull` в его каталоге. Положите образ эмулятора из раздачи организаторов в `data/emulator/`. Два CSV уже входят в репозиторий:

```text
transport2/
├── compose.yaml
└── data/
    ├── emulator/
    │   └── ndtp-telemetry-emulator.tar  ← положить вручную
    └── validate/
        ├── traffic.csv                  # уже в репозитории
        └── schedule_plan.csv            # уже в репозитории
```

Модель, карта и готовый интерфейс также входят в репозиторий. Один раз загрузите образ эмулятора, затем выполните команду быстрого запуска:

```sh
docker load -i data/emulator/ndtp-telemetry-emulator.tar
```

## Что посмотреть

1. Дождитесь появления транспорта на карте и движения времени данных в шапке.
2. Выберите транспортное средство: карточка показывает прогноз задержки на остановке через 10–15 минут. Если прогноз недоступен, там же указана причина.
3. Откройте «События»: предупреждения появляются при прогнозе задержки больше двух минут. В «Диагностике» растут счётчики принятых кадров и успешных расчётов модели.

Демо проигрывает два часа данных с ускорением ×5 — около 24 минут. Затем поток штатно завершается, последний результат остаётся на экране. Для нового прогона повторите команду быстрого запуска.

## Порты и документация

Для просмотра нужен только [localhost:8002](http://localhost:8002). Остальные порты обслуживают отдельные компоненты: `8000` — ML API, `8001` — Backend API, `9201` — приём NDTP, `18080` — управление эмулятором. Compose связывает их автоматически; текущая конфигурация публикует все пять портов, поэтому они должны быть свободны.

При необходимости: Swagger [ML](http://localhost:8000/docs), [Backend](http://localhost:8001/docs), [дашборда](http://localhost:8002/docs); [PyDoc](../pydoc/index.html) можно открыть локально в браузере. Настройки и разбор ошибок — в [подробной инструкции](local-demo.md).

## Остановка

```sh
docker compose --profile demo down
```

Файлы данных и модели сохраняются; состояние текущего прогона сбрасывается.
