transport2 — PyDoc

Документация Python-модулей трёх сервисов демо: ML API, Backend и consumer. Файлы сгенерированы стандартным pydoc -w из кода этого commit. OpenAPI-спецификации сервисов лежат рядом, в docs/api/.

ML API (transport_ml, порт 8000)

МодульНазначение
transport_ml.final_modelВыбранная финальная модель и каноничный point-in-time инференс.
transport_ml.serviceHTTP-граница финальной модели (FastAPI, uvicorn transport_ml.service:app).
transport_ml.dataКонтракты данных; факты не попадают в расписание для признаков.
transport_ml.featuresОдна реализация признаков для исторических батчей и онлайн-запросов.

Backend (transport_backend, порт 8001, NDTP 9201)

МодульНазначение
transport_backend.serviceHTTP API Backend (FastAPI, uvicorn transport_backend.service:app).
transport_backend.orchestrationЖизненный цикл прогноза поверх point-in-time состояния NDTP и плана.
transport_backend.runЕдинственный владелец часов источника и демо-прогона.
transport_backend.ingestTCP-сервер NDTP с ограниченной очередью и явными доменами времени.
transport_backend.ndtpФрейминг NDTP и поднабор ячеек эмулятора фиксированной длины.
transport_backend.scheduleПлановые прибытия и консервативные наблюдения остановок только по GPS.
transport_backend.stateОграниченное point-in-time состояние телеметрии одного процесса Backend.

Consumer (consumer, порт 8002)

МодульНазначение
consumer.serviceРаздача диспетчерской карты, снимка ТС и маршрутного контекста из Backend.

OpenAPI

  • docs/api/openapi.json — ML API (Transport Final Model API)
  • docs/api/backend-openapi.json — Backend (Transport Backend API)
  • docs/api/consumer-openapi.json — consumer (Transport live consumer)

После запуска стека по README Swagger UI доступен на http://localhost:8000/docs, :8001/docs и :8002/docs.

Как пересобрать

Из корня репозитория с установленным requirements.txt. Второй sed убирает абсолютные пути host, третий — адреса памяти в схемах pydantic, чтобы повторная генерация давала тот же файл.

cd docs/pydoc && PYTHONPATH=../.. ../../.venv/bin/python -m pydoc -w transport_ml.final_model transport_ml.service transport_ml.data transport_ml.features transport_backend.service transport_backend.orchestration transport_backend.run transport_backend.ingest transport_backend.ndtp transport_backend.schedule transport_backend.state consumer.service
sed -i '' "s#$(cd ../.. && pwd)/##g" *.html
sed -i '' -E "s#('ref': '[A-Za-z_][A-Za-z0-9_.]*):[0-9]+'#\1'#g" *.html

Ссылки file:… в заголовках модулей указывают путь исходника от корня репозитория.
