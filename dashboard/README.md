# Dashboard

Каталог зарезервирован для диспетчерского BI-дашборда. Компонент ещё не реализован.

По официальным критериям будущий интерфейс должен за несколько секунд показывать проблемные транспортные средства и участки, карту текущего положения, зелёный/жёлтый/красный риск и карточку инцидента с прогнозом опоздания, предполагаемой причиной и участком маршрута. Данные должны обновляться вслед за потоком.

Контракт данных и технологию дашборда следует выбрать после проверки ML API и владельца потокового состояния в Backend.
