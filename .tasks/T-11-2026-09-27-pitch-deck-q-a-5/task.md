# T-11: Pitch: история, deck, демо-сценарий, запись, Q&A, проверка за 5 секунд

## Outcome

Primary goal: Команда готова к полуфинальному pitch по финальной сборке T-7. Есть история в 3 такта, deck на 8–10 слайдов, где каждое число имеет источник, демо-сценарий на 2–3 мин с таймкодами, резервная запись 1920×1080 с build identity и Q&A на 20–25 вопросов, проверенный mock-ревью. Также проведена проверка понимания экрана «за 5 секунд» на людях, не писавших экран.
Direction: on-track
Comment: pitch сейчас 3–4/10 (P1 1, P2 2, P3 0–1). Материалы T-6 относятся к удалённому UI-сценарию. Проверка «за 5 секунд» — прямое требование C4. Обоснование — [score-plan](../T-7-2026-09-27-ml/artifacts/score-plan.md) §4.

Неудачный путь: если число не подтверждено к моменту выступления, в deck пишется «не измерено» и оно попадает в «ограничения». Если участник проверки «за 5 секунд» не находит проблемное ТС, это записывается как finding для UI, а не исправляется в этой задаче.

## Decisions

- Каждое число и утверждение в deck, сценарии и Q&A ссылается на строку `numbers.md` или на файл evidence. Запрещено: «доказанное раннее предупреждение» (без результата T-9), «трасса» (это линия через плановые остановки), «вероятность» и «причина задержки», «команда отправлена водителю».
- Текст (история, Q&A, каркас deck) начинается сейчас. Скриншоты, запись, сценарий с таймкодами и проверка «за 5 секунд» — только после T-7 W10 на той же сборке (build identity записывается рядом).
- Deck: источник `artifacts/pitch/deck.md`; экспорт в формат, который выберет пользователь (по умолчанию `.pptx`; score-plan Q2).
- Проверку «за 5 секунд» проходят люди, не писавшие экран (score-plan Q5). Агент по скриншоту допустим только как запасной вариант с подписью «не человек» и не повышает C4.
- Mock Q&A проводит независимый агент-«жюри», не писавший ответы: 10 вопросов, оценка каждого ответа 0–2, один цикл доработки ответов с оценкой < 2.
- Репетиции проводят люди (пользователь и команда). Агент готовит материалы и записывает замечания в Execution log.
- Внешняя публикация deck или видео не входит в задачу.

## Boundary

- **Included:** `artifacts/pitch/**` (story, numbers, deck.md и экспорт, demo-script, запись, qa, mock-review, five-second-check); передача findings по UI и docs владельцам.
- **Excluded:** правки UI, product code, README и runbook (findings — владельцам); новые измерения (T-9, T-10); отправка или публикация.
